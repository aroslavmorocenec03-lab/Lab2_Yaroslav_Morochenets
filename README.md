## Лабораторна № 1

Створено `student.html`, `junior.html` і `senior.html`, показано зміни робочого дерева, індексування та окремі коміти. Файл `student.html` містить ім’я та прізвище; прізвище виділено тегом `<b>`.

## Лабораторна № 2

У гілці `new_feature` додано операцію `pow(a, b)`. Після компіляції та перевірок гілку об’єднано в `master` і видалено. Позначка `lab2-complete` зберігає результат. Повну історію, гілки й позначки надіслано командами Git до цього публічного репозиторію.

## Калькулятор

Збирається як C++17:

```powershell
zig c++ -std=c++17 -Wall -Wextra calc.cpp -o calc.exe
```

Альтернатива з GCC: `g++ -std=c++17 -Wall -Wextra calc.cpp -o calc.exe`.

Порядок введення: перше число, номер операції, друге число. Операції: 1 — додавання, 2 — віднімання, 3 — множення, 4 — ділення, 5 — степінь. Програма перевіряє помилкове введення, невідому операцію, ділення на нуль і нескінченний результат.

Перевірено: `6 + 4 = 10`, `6 - 4 = 2`, `6 * 4 = 24`, `5 / 2 = 2.5`, `2^3 = 8`, `2^(-2) = 0.25`; ділення на нуль повертає повідомлення про помилку.

## Особливості виконання

Команди виконано у PowerShell. Для файлових дій використано Windows-еквіваленти `New-Item`, `Copy-Item` і `Set-Content`. Налаштування `git config --global` ізольовано у файлі навчального сеансу через `GIT_CONFIG_GLOBAL`.

Це відхилення явно зазначено у звіті. `.gitignore` розміщено в корені робочого дерева, як вимагає Git.
